# Password Strength Checker 🛡️

A Python-based tool designed to evaluate password security using specific complexity criteria.

## Features
- **Length Analysis:** Checks if the password meets the 8 and 12-character milestones.
- **Digit Detection:** Verifies the presence of numbers.
- **Casing Verification:** Ensures both uppercase and lowercase letters are used.
- **Symbol Detection:** Scans for special characters (e.g., @, #, $, %).
